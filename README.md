# AI Personal Portfolio Website Builder
## Overview
A responsive, single-page student portfolio built with HTML, CSS, and a little JavaScript. AI can assist with 
brainstorming the structure, drafting starter copy, and explaining code; review and customize all outputs 
before use.
## Run locally
1. Extract the ZIP.
2. Open `portfolio-website/index.html` in a modern browser.
3. Edit the HTML and CSS to personalize it. No build tools or dependencies are required.
## Personalize before submitting or publishing
- Replace “Alex Morgan” with your name.
- Replace the biography, skills, and sample projects with accurate details.
- Change `hello@example.com` to an email you are comfortable sharing.
- Replace or remove the example GitHub and LinkedIn links.
- Add links/screenshots for real projects and ensure media is yours or properly licensed.
## Features
- Responsive layout for desktop and mobile
- Mobile navigation toggle
- About, skills, projects, and contact sections
- Email link (opens an email application; no backend)
- Dynamic copyright year
## Limitations
This is a static front-end demo. It is not hosted on the internet and does not have a backend, database, or 
server-side contact form. The identity and sample project descriptions are placeholders.
